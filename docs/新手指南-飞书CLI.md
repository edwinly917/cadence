# 新手指南 · 飞书每日待办自动扫描（飞书 CLI）

> 这份指南假设你**完全没用过命令行**，每一步都告诉你在**哪台设备、哪个界面、点哪里**。
> 照着从上往下做即可。遇到名词先看下面的「名词解释」。

---

## 0. 这个功能是干嘛的？

让电脑每天**自动**去看你的飞书消息，用 AI 把里面的「待办事项」挑出来：
- 能明确判断（重要/紧急 + 截止日期）的 → 直接放进 Cadence 看板的四象限。
- 判断不清的 → 放进「待定」收件箱，你之后手动整理。

每天早上 8 点自动跑一次，你不用管。

---

## 1. 名词解释（看不懂就回来查）

| 名词 | 大白话 |
|---|---|
| **终端 / Terminal** | Mac 上一个**黑色的输入命令的窗口**。下面教你怎么打开。 |
| **命令** | 一行字，复制粘贴到终端里、按回车，电脑就照做。 |
| **飞书开放平台** | 飞书给开发者用的网站，在**电脑浏览器**里打开，用来创建「机器人应用」。 |
| **App ID / App Secret** | 飞书应用的「账号和密码」，一串字符。程序拿它去读你的飞书消息。 |
| **API Key（Anthropic）** | 调用 AI（Claude）的钥匙，一串 `sk-ant-` 开头的字符。 |
| **.env 文件** | 一个**存放上面这些钥匙**的文本文件，放在项目里。 |
| **PR** | GitHub 上的「代码合并申请」。你点一下「Merge」就把这次改动正式收进项目。 |

> 这一切都在你的 **Mac 电脑**上操作，**不需要用手机**。

## 2. 先打开「终端」（以后每条命令都在这里跑）

1. 按键盘 **`Command（⌘）+ 空格`**，屏幕中间会弹出搜索框。
2. 输入 `终端` 或 `Terminal`，按 **回车**。
3. 出现一个可以打字的窗口 —— 这就是终端。

> 以后说「跑某条命令」，就是：**复制那行字 → 在终端里粘贴（`⌘+V`）→ 按回车**。

先跑这条，进入项目文件夹（以后每次操作前都先跑它）：
```bash
cd /Users/bytedance/Desktop/cadence/ingest
```

---

## 3. 拿「飞书钥匙」（在电脑浏览器里做）

1. 用**电脑浏览器**打开：https://open.feishu.cn
2. 用你的飞书账号**登录**，进入「**开发者后台**」。
3. 点「**创建企业自建应用**」，随便起个名字（比如 `cadence-待办扫描`）。
4. 创建后进入这个应用，左侧找「**凭证与基础信息**」：
   - 复制 **App ID**（形如 `cli_xxxxx`）
   - 复制 **App Secret**（一长串字符）
   先把这两个**贴到「备忘录」里**，待会儿要用。
5. 左侧「**权限管理**」→ 搜索并开通这两个权限：
   - `im:message:readonly`（读消息）
   - `im:chat:readonly`（读会话/群）
6. 左侧「**应用功能 → 机器人**」，把**机器人能力打开**。
7. 左侧「**版本管理与发布**」→ 创建一个版本并**发布**（自建应用要发布后权限才生效）。

> 做完这步你手上有两样东西：**App ID** 和 **App Secret**。

---

## 4. 把机器人「拉进群」（在飞书 App 或电脑飞书里做）

程序只能读到「机器人所在的群」的消息。所以：

1. 打开你想让它扫描的**飞书群**。
2. 群右上角「**设置（…）**」→「**群机器人**」→「**添加机器人**」。
3. 搜索你刚创建的应用名字，添加进去。
4. 想扫几个群就把机器人加进几个群。

> ⚠️ 注意：这种方式**读不到你和别人的一对一私聊**。私聊需要额外的「用户授权」（进阶，本指南先不做）。

---

## 5. 拿「AI 钥匙」（Anthropic API Key，在电脑浏览器里做）

1. 电脑浏览器打开：https://console.anthropic.com
2. 注册 / 登录（需要绑定一张信用卡充值，AI 调用按量计费，扫消息花费很小）。
3. 左侧「**API Keys**」→「**Create Key**」→ 复制那串 `sk-ant-...`，贴到备忘录。

---

## 6. 把三把钥匙填进 `.env` 文件

1. 回到**终端**，先复制一份配置模板：
   ```bash
   cd /Users/bytedance/Desktop/cadence/ingest
   cp .env.example .env
   ```
2. 用「文本编辑」打开它（这条命令会自动弹出编辑窗口）：
   ```bash
   open -e .env
   ```
3. 在弹出的窗口里，把等号后面填上你的真实值（**不要加引号、不要留空格**）：
   ```
   FEISHU_APP_ID=cli_你的AppID
   FEISHU_APP_SECRET=你的AppSecret
   ANTHROPIC_API_KEY=sk-ant-你的Key
   ```
   其它行（`ANTHROPIC_MODEL` 等）保持默认即可。
4. 按 **`⌘+S`** 保存，关闭窗口。

> ✅ 安全提示：`.env` 已经被设置为**不会上传到 GitHub**，钥匙不会泄露。

## 7. 先「离线试跑」一次（不连飞书，验证流程通）

这一步用内置的假消息，确认 AI 分类能跑（**不会动你的真实数据**）。

1. 终端里临时加一行假数据来源（在 `.env` 里加，或直接这样跑）：
   ```bash
   cd /Users/bytedance/Desktop/cadence/ingest
   FEISHU_FIXTURE=fixtures/sample-messages.json node dist/cli.js --dry-run
   ```
2. 你应该看到类似输出：
   ```
   [AUTO-FILE] 下周三前交报销   ...
   [PENDING ]  看竞品文档       ...
   ```
   - `AUTO-FILE` = 会进四象限；`PENDING` = 会进待定。
   - 看到这种结果就说明 **AI 分类正常**。

---

## 8. 真实跑一次（连飞书，写进 Cadence）

1. 先**只看不写**（`--dry-run` 只打印、不改数据）：
   ```bash
   cd /Users/bytedance/Desktop/cadence/ingest
   node dist/cli.js --dry-run
   ```
   看看它从你的飞书群里抓出了哪些待办。
2. 满意了，**正式写入**：
   ```bash
   node dist/cli.js
   ```
3. 打开 **Cadence 应用**，看「看板」和「待定」标签，应该能看到新任务了。

## 9. 看「每天扫到了什么」（追踪记录）

随时在终端跑：
```bash
cd /Users/bytedance/Desktop/cadence/ingest
node dist/cli.js --history
```
会按天列出每次扫描的结果（✅入象限 / 📥待定）。文件也存在 `ingest/state/history.md`，可以直接用文本编辑器看。

## 10. 每天自动跑（已经帮你设好了）

电脑里已经装了一个**定时任务**，每天**早上 8 点**自动跑一次（只要电脑开着）。
- 你只要做完第 3–6 步（填好钥匙、加好机器人），它就会开始自动出活。
- 想**立刻试一次**别等到 8 点，跑这条：
  ```bash
  launchctl kickstart -k gui/$(id -u)/com.willyliu.cadence.ingest
  ```
- 运行日志在 `ingest/state/ingest.log`（成功）和 `ingest/state/ingest.err.log`（报错）。

## 11. 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| `缺少必需的环境变量` | `.env` 没填或填错。回第 6 步检查。 |
| 飞书报 `99991663` / 权限错误 | 权限没开或没发布版本。回第 3 步第 5、7 点。 |
| 抓不到某个群的消息 | 机器人没加进那个群。回第 4 步。 |
| `找不到 cadence 数据库` / 缺表 | 先打开一次 Cadence 应用（迁移这步其实已经帮你做过了，正常不会遇到）。 |
| 私聊消息抓不到 | 正常，tenant 模式读不到私聊，需要进阶的用户授权。 |
